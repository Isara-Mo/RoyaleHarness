# 发行范围

这是从开发工程按文件白名单提取的独立副本。原工程的日志、备份、诊断资料和配置不会随包发布。

包含：`AGENTS.md` 与配置技能、桥接／推理／执行源码、稳定探针及其完整构建源码、合成测试、便携配置、安装恢复工具、启动菜单和本文档。
排除：原始游戏／SDK 二进制、APK、模型权重、上游资源、原始回放、截图、个人配置、账号、虚拟环境和实验产物。
公开探针 `.so` 是本项目源码编译的代理，不是原始游戏 SDK。

运行 FirstLight 依赖由使用者另行获取，`upstream.lock.json` 记录测试版本和相关文件指纹。
冻结的是推理兼容基线，不要求用户复制开发者的离线引擎安装配置。

发布适配只改配置入口、安装／恢复、首次验证门槛和文档；模型特征、默认稳定探针及执行策略保留当前基线。
预编译探针不是通用版本，游戏内容变化需要重新研究适配，不能绕过指纹检查。

## 重新打包

不要直接压缩正在使用的目录。先运行 `tools/package_release.py`，工具验证稳定探针、检查受控文件中的
开发机路径和已知个人标识，仅将 `SHA256SUMS.json` 中列出的文件打包，排除运行过程中产生的所有文件。
源码修改后应重新审查并生成清单，不能把本机配置加进清单。
个人 SDK 备份和运行日志仅应留在本地。

Git 文本文件统一使用 LF，BAT 使用 CRLF；打包校验按同一规则处理换行符。
只有换行符差异会被规范化，源码内容变更仍需重新审查，探针二进制始终逐字节校验。

## 已知部署限制

- 当前仅支持 Windows、Root MuMu、精确匹配的 ARM64 游戏版本。
- 需要使用者先在 MuMu 中启用 Root、ADB 并连接正确实例。
- 游戏 SDK 代理要求原始库的全部转发符号可用；缺失时安装拒绝。
- 第一次安装会保留原始 SDK；恢复按模拟器地址和安装目录隔离，更新游戏后不复用旧目录备份。
- 安装步骤完成前后均检查文件指纹；若安装中断导致游戏仍停止，先检查错误和备份后运行恢复命令。
- 原生遥测监听端口 26888。只在本地测试环境使用，不将它转发到公共网络。

已在同一电脑的新实例完成安装和整局实战；具体覆盖与限制见 [验证记录](VALIDATION.md)。
